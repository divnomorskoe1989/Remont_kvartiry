# Технические задания по помещениям

В этой папке хранятся актуальные технические задания на дизайн и ремонт для каждого помещения квартиры.

## Правила

- Перед созданием или изменением дизайна сначала читать корневой [README](../README.md), затем ТЗ нужного помещения.
- ТЗ имеет приоритет над старыми визуализациями и промежуточными схемами, если в нём явно зафиксированы более поздние решения.
- Размеры со статусом «ориентировочно», «допущение» или «требует замера» нельзя использовать как фактические размеры для заказа мебели, дверей, стекла и других изделий.
- Для каждого помещения создаётся отдельный файл. При изменении согласованной планировки или размеров обновляется соответствующее ТЗ, а не создаётся противоречащая версия в другом месте.
