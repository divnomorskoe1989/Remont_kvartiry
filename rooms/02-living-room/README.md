# Зал — комната №2

## Источники
- Геометрия: [основной README](../../README.md), комната 5,74 × 3,36 м, площадь 19,3 м², расчётная высота 2,50 м.
- Исходный план: `plans/source/apartment-plan-public.png` (подготовлен, **ещё не загружен**).
- 10 фотографий текущего состояния: `rooms/02-living-room/photos/2026-10-11/` (**ещё не загружены**).

## Ориентация
На плане комната №2 расположена справа от прихожей, её наружная стена с окном — нижняя сторона схемы (отрезок 3,36 м). Фотографии показывают широкое трёхсекционное окно, подоконник, радиатор и трубы рядом с окном. Окно на снимках соответствует окну О1 в основном README, **не кухонному балконному блоку**. При создании дизайна сверять окно, дверь и длины стен с планом; не зеркалить комнату по фотографиям.

## Мебель
- Тёмный шкаф с зеркальными створками: **200 см вдоль стены × 50 см глубина** (со слов владельца). Высота неизвестна. Предположительно сохраняется, допускается перестановка.
- Кровать с тёмным изголовьем: присутствует, решение о сохранении не принято, размеры неизвестны.
- Серый диван, стол, табурет и матрасы: присутствуют на фото, размеры и дальнейшая судьба не уточнены.
- Кондиционер над диваном у окна; под окном радиатор. Учитывать доступ к ним и ограничения перестановки.

## Отделка и состояние
- Пол: покрытие с рисунком под дерево, точный материал по фото не установлен.
- Стены: белые фактурные обои/покрытие; есть следы крепежа, пятна.
- Потолок: светлый, видны тонкие трещины/линии; способ отделки не установлен. Перед косметическим ремонтом оценить характер трещин.
- Дверь: белая распашная со стороны прихожей.

## Инструкция агенту
Перед дизайном читать корневой README, этот файл, план и все фото комнаты. Использовать реальные размеры как ограничения; не менять положение окон, двери, радиатора и кондиционера без явного запроса. Сначала проверять габариты сохраняемой мебели и свободные проходы. Не выдавать визуальные оценки за обмер. Для новых комнат создавать отдельную папку `rooms/<номер>-<название>/`, README и `photos/<дата>/`. В корневом README добавлять навигацию. Исходные изображения не заменять генерациями. В публичный репозиторий не помещать адреса, телефоны и лица без очистки.
